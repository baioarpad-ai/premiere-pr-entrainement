# Premier dépôt d'entraînement

Ce dépôt sert à s'entraîner au workflow des Pull Requests sur GitHub.

## Objectif

Apprendre à :
- créer une branche
- faire une petite modification
- ouvrir une Pull Request
- répondre aux commentaires de relecture
- la fusionner
